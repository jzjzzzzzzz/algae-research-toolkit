# Research references and retained materials

The original `base-algae` repository included a presentation and two reference
PDFs. `docs/presentations/Base.pptx` is retained in this consolidation. The
reference PDFs remain available in the archived source repository rather than
being duplicated into the maintained package:

- `EEC-33.pdf`
- `Journal of Nanomaterials - 2015 - Hsia - Enhancing Algal Growth by Stimulation with LED Lighting and Ultrasound.pdf`

Keeping the historical repository intact preserves the research workspace
without treating third-party documents as package assets. Future references
should include a full citation, DOI or canonical URL, access date, and a note
explaining which model parameter or experimental choice the source informs.
