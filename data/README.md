# Data inventory

`legacy/base-algae-sound-experiment-log.csv` is the original session log from
the archived `base-algae` repository. It is retained unchanged for provenance,
including failed browser sessions and the historical schema transition from
nine to eleven columns.

New runs use a consistent nine-column schema and should be written to the
git-ignored `outputs/` directory unless a reviewed dataset is intentionally
added to this repository.
